LOAN HUB - QUICK START GUIDE
=============================

**BEFORE YOU START:**
✓ Java 17+ installed
✓ PostgreSQL 12+ installed and running
✓ Maven 3.6+ installed

**STEP 1: Setup Database (5 minutes)**
================================================

1. Open PostgreSQL Command Line (pgAdmin or psql):
   - Windows: Open "SQL Shell (psql)"
   - Mac/Linux: Open terminal and run: psql -U postgres

2. Copy and paste ALL of these commands:

   CREATE DATABASE loan_app_db;
   CREATE USER loan_user WITH PASSWORD 'loan_password123';
   ALTER ROLE loan_user SET client_encoding TO 'utf8';
   ALTER ROLE loan_user SET default_transaction_isolation TO 'read committed';
   ALTER ROLE loan_user SET default_transaction_deferrable TO on;
   ALTER ROLE loan_user SET timezone TO 'UTC';
   GRANT ALL PRIVILEGES ON DATABASE loan_app_db TO loan_user;

3. Verify by running: \l
   You should see "loan_app_db" in the list

4. Exit: \q


**STEP 2: Download and Extract Project (2 minutes)**
================================================

1. Download the ZIP file from v0
2. Extract to desired location
3. Open Command Prompt/Terminal in the extracted folder


**STEP 3: Build Spring Boot (5 minutes)**
================================================

1. Run command:
   mvn clean install

2. Wait for "BUILD SUCCESS" message


**STEP 4: Start Application (2 minutes)**
================================================

1. Run command:
   mvn spring-boot:run

2. Wait for message:
   "Started LoanAppApplication in X.XXX seconds"

3. Application is now running on: http://localhost:8080


**STEP 5: Access Application in Browser (1 minute)**
================================================

1. Open your browser (Chrome, Firefox, Edge, Safari)
2. Go to: http://localhost:8080
3. You should see the beautiful Loan Hub website!

**TROUBLESHOOTING:**
================================================

ERROR: "Connection refused" or "Cannot connect to database"
FIX: Make sure PostgreSQL is running:
     Windows: Services → PostgreSQL → Start
     Mac: Open Postgres.app or use: brew services start postgresql

ERROR: Port 8080 is already in use
FIX: Kill the process or change port in application.properties:
     server.port=8081

ERROR: "BUILD FAILURE" from Maven
FIX: Run: mvn clean
     Then: mvn install

ERROR: Cannot find application.properties
FIX: Make sure you're in the correct directory
     Run: dir (Windows) or ls (Mac/Linux)
     You should see "pom.xml" and "src" folder

ERROR: Cannot access http://localhost:8080
FIX: Wait 10-15 seconds after seeing "Started LoanAppApplication"
     Check console for any errors
     Try clearing browser cache (Ctrl+Shift+Delete)
